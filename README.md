# Mon Chocolat

Site institucional demonstrativo de uma confeitaria fictícia, criado com HTML, CSS e JavaScript. O projeto apresenta a marca, destaca produtos e organiza o cardápio em páginas para cookies, brownies, donuts e bolos.

> Este é um projeto demonstrativo. Os canais de contato exibidos não oferecem atendimento real.

## Páginas

- `pages/inicio.html`: apresentação da marca e produtos favoritos.
- `pages/cookie.html`: cardápio de cookies.
- `pages/brownie.html`: cardápio de brownies.
- `pages/donut.html`: cardápio de donuts.
- `pages/bolo.html`: cardápio de bolos.
- `pages/contato.html`: informações demonstrativas de contato e encomendas.
- `index.html`: redireciona para a página inicial.

## Tecnologias

- HTML5, CSS3 e JavaScript.
- Bootstrap 5.3.8 e Bootstrap Icons, carregados por CDN.
- Imagens de produtos hospedadas no Cloudinary.

## Site publicado

Acesse o site da Mon Chocolat: [mon-chocolat-topaz.vercel.app](https://mon-chocolat-topaz.vercel.app/).

## Estrutura do projeto

```text
.
├── css/
│   └── style.css        # estilos compartilhados
├── fonts/               # fontes locais usadas pelo site
├── imgs/                # logotipo, banners, produtos, ícones e favicon
├── js/
│   └── script.js        # animações e renderização dos produtos
├── pages/               # páginas HTML do site
├── index.html           # redirecionamento para a página inicial
├── LICENSE
└── README.md
```

## Conteúdo e manutenção

As listas de produtos e os destaques são definidos no arquivo `js/script.js`. Os estilos ficam em `css/style.css`; imagens e fontes locais ficam nas pastas `imgs/` e `fonts/`. Ao adicionar ou renomear arquivos, confira também os caminhos relativos usados nas páginas dentro de `pages/`.

# Mon Chocolat

A showcase website for a fictional bakery, built with HTML, CSS, and JavaScript. It introduces the brand, highlights products, and organizes the menu into pages for cookies, brownies, donuts, and cakes.

> This is a demonstration project. The contact channels shown do not provide real customer service.

## Pages

- `pages/inicio.html`: brand introduction and customer favorites.
- `pages/cookie.html`: cookie menu.
- `pages/brownie.html`: brownie menu.
- `pages/donut.html`: donut menu.
- `pages/bolo.html`: cake menu.
- `pages/contato.html`: demonstration contact and ordering information.
- `index.html`: redirects to the home page.

## Technologies
- HTML5, CSS3, and JavaScript.
- Bootstrap 5.3.8 and Bootstrap Icons, loaded from a CDN.
- Product images hosted on Cloudinary.

## Live site

Visit the Mon Chocolat [mon-chocolat-topaz.vercel.app](https://mon-chocolat-topaz.vercel.app/).

## Project structure

```
├── css/
│   └── style.css        # shared styles
├── fonts/               # locally used fonts
├── imgs/                # logo, banners, products, icons, and favicon
├── js/
│   └── script.js        # animations and product rendering
├── pages/               # website HTML pages
├── index.html           # redirects to the home page
├── LICENSE
└── README.md
```

## Content and maintenance

Product lists and featured items are defined in js/script.js. Styles are in css/style.css; local images and fonts are in the imgs/ and fonts/ folders. When adding or renaming files, also check the relative paths used by pages inside pages/.
